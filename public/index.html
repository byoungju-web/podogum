화면과 검색
A 언어 · Language 자동

화면 글자와 검색 결과의 언어가 함께 바뀝니다. Brave는 해당 국가 결과를, 위키백과는 해당 언어판을 우선합니다.

자동으로 두면 접속한 나라를 보고 정합니다. 한국에서 열면 한국어, 태국에서 열면 ไทย 입니다. 나라를 못 알아내면 기기 언어를 씁니다.

검색 소스 키
B Brave 웹검색 미등록

자기 키를 넣으면 웹 검색이 무제한이 됩니다. 요금은 본인 계정으로 나가고, 매달 $5 무료 크레딧(약 1,000회)이 들어옵니다. 대부분은 이 안에서 끝납니다.

  1. api-dashboard.search.brave.com/register 에서 가입합니다.
  2. 메일 인증을 마칩니다.
  3. 왼쪽 Subscriptions › Available plans 에서 Search 플랜을 고릅니다.
  4. 카드를 등록합니다. 크레딧 안에서만 쓰면 청구되지 않습니다.
  5. 중요 · Subscriptions › Usage limits 에서 Free credits only 로 잠그세요. 무료 크레딧을 넘겨 쓰는 일이 없어서 요금이 나올 수 없습니다.
  6. Dashboard › API keys 에서 Add API key 로 키를 만들어 위 칸에 붙여넣습니다.
T Tavily 웹검색 미등록

Brave와 같은 종합 웹 검색입니다. 둘을 함께 쓰면 서로 겹치는 문서가 생겨 순위가 정확해집니다. 월 1,000회 무료이고 카드 등록이 없습니다.

  1. app.tavily.com 에서 가입합니다. 구글 계정이 가장 빠릅니다.
  2. 대시보드 API Keys 에 키가 이미 하나 만들어져 있습니다.
  3. tvly- 로 시작하는 키를 복사해 위 칸에 붙여넣습니다.
  4. 카드는 등록하지 마세요. 월 1,000회를 다 쓰면 그냥 멈추고 요금이 나올 수 없습니다.
여 국내여행 · 한국관광공사 미등록

국내 맛집·숙소·관광지를 실제 상호와 주소로 찾습니다. 웹 검색은 블로그 글을 주는데 이건 장소 자체를 줍니다. 무료이고 하루 1,000회입니다. 넣지 않으면 칸 자체가 보이지 않습니다.

  1. data.go.kr 에 가입하고 로그인합니다.
  2. 한국관광공사 국문 관광정보 서비스 를 검색합니다.
  3. 활용신청 을 누릅니다. 개발계정은 자동 승인이라 기다리지 않습니다.
  4. 마이페이지 › 인증키 발급현황 으로 갑니다.
  5. 일반 인증키 를 복사해 위 칸에 넣으세요. Encoding · Decoding 어느 쪽이든 알아서 처리합니다.
  6. 승인 직후 몇 분에서 한 시간쯤은 키가 인증되지 않을 수 있습니다. 그때는 조금 뒤에 다시 시도하세요.
N 내 노션 미등록

내 노션 문서를 웹 검색과 같은 화면에서 한 번에 찾습니다. 넣지 않으면 칸 자체가 보이지 않습니다. 무료입니다.

  1. notion.so/my-integrations 에서 New integration 을 누릅니다.
  2. 이름을 적고 워크스페이스를 고른 뒤 종류는 Internal 로 합니다.
  3. 권한은 Read content 만 켜세요. 쓰기와 댓글은 필요 없습니다.
  4. Internal Integration Secret 을 복사해 위 칸에 넣습니다.
  5. 중요 · 노션에서 검색할 페이지를 열고 ··· → 연결 추가 에서 방금 만든 연결을 고르세요. 이걸 안 하면 아무것도 안 나옵니다.

노션 API는 브라우저에서 직접 부를 수 없어 요청이 검색 서버를 거쳐 갑니다. 토큰은 저장되지 않지만, 회사 문서라면 필요한 페이지만 연결하시는 편이 안전합니다.

S Stack Overflow 미등록

없으면 공용 IP 할당량에 걸려 거의 항상 막힙니다. 키를 넣으면 하루 300회에서 10,000회로 올라갑니다.

  1. stackapps.com/apps/oauth/register 에 접속해 로그인합니다.
  2. 앱 이름과 한 줄 설명을 적습니다. 심사는 없습니다.
  3. 약관에 체크하고 Register application 을 누릅니다.
  4. 만료일을 물으면 Never 를 고릅니다.
  5. 값 세 개 중 Key 만 복사해 위 칸에 넣으세요. Client Secret은 어디에도 넣지 마세요.

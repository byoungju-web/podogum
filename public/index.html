PARALLEL · RRF FUSION

검색 서버 주소는 보통 비워두면 됩니다. podogum.kr에서 열면 같은 도메인의 API를 알아서 씁니다.

발급받은 코드를 넣으면 남은 횟수만큼 웹 검색이 열립니다.

자기 키를 넣으면 웹 검색이 무제한이 됩니다. 요금은 본인 계정으로 나가고, 매달 $5 무료 크레딧(약 1,000회)이 들어옵니다. 대부분은 이 안에서 끝납니다.

Brave 키 받는 방법 · 5분
  1. api-dashboard.search.brave.com/register 에서 가입합니다.
  2. 메일 인증을 마칩니다.
  3. 왼쪽 Subscriptions › Available plans 에서 Search 플랜을 고릅니다. $5 / 1,000회이고 매달 $5 크레딧이 자동으로 들어옵니다.
  4. 카드를 등록합니다. 크레딧 안에서만 쓰면 청구되지 않습니다.
  5. 중요 · Subscriptions › Usage limits 에서 Free credits only 로 잠그세요. 이렇게 하면 무료 크레딧을 넘겨 쓰는 일이 아예 없어서 요금이 나올 수 없습니다.
  6. Dashboard › API keys 에서 Add API key 를 눌러 키를 만듭니다.
  7. 그 키(BSA... 로 시작)를 위 칸에 붙여넣고 저장합니다.

내 노션 문서를 웹 검색과 같은 화면에서 한 번에 찾습니다. 넣지 않으면 칸 자체가 보이지 않습니다. 무료입니다.

노션 토큰 받는 방법 · 5분
  1. notion.so/my-integrations 에 접속합니다.
  2. New integration 을 누릅니다.
  3. 이름을 적고, 사용할 워크스페이스를 고릅니다.
  4. 종류는 Internal 을 고릅니다. 나 혼자 쓰는 연결입니다.
  5. 권한에서 Read content 만 켜세요. 쓰기와 댓글 권한은 필요 없습니다.
  6. 저장하면 Internal Integration Secret 이 나옵니다. Show 를 눌러 복사해 위 칸에 넣으세요.
  7. 중요 · 노션에서 검색할 페이지를 열고 오른쪽 위 ··· → 연결 추가(Add connections) 에서 방금 만든 연결을 고르세요. 이 작업을 안 하면 아무것도 안 나옵니다. 상위 페이지에 걸면 하위 페이지도 함께 열립니다.

노션 API는 브라우저에서 직접 부를 수 없어서 요청이 검색 서버를 거쳐 갑니다. 토큰은 저장되지 않지만, 회사 문서라면 필요한 페이지만 연결하시는 편이 안전합니다. 검색은 주로 제목을 기준으로 찾습니다.

Brave와 같은 종합 웹 검색입니다. 둘을 함께 쓰면 서로 겹치는 문서가 생겨 순위가 정확해집니다. 월 1,000회 무료이고 카드 등록이 없습니다.

Tavily 키 받는 방법 · 3분
  1. app.tavily.com 에 접속합니다.
  2. Sign up 을 눌러 가입합니다. 구글 계정으로 하면 가장 빠릅니다.
  3. 가입하면 바로 대시보드가 열리고 API Keys 항목에 키가 하나 이미 만들어져 있습니다.
  4. tvly- 로 시작하는 그 키를 복사합니다. 눈 모양이나 복사 아이콘을 누르면 보입니다.
  5. 위 칸에 붙여넣고 저장합니다.
  6. 카드는 등록하지 마세요. 등록하지 않으면 월 1,000회를 다 쓴 뒤 그냥 멈추고, 요금이 나올 수가 없습니다.

내 노션 문서를 웹 결과와 나란히 검색합니다. 토큰을 넣어야 칸이 나타납니다. 이 브라우저에만 저장되고 서버에는 남지 않습니다.

Notion 토큰 받는 방법 · 5분
  1. notion.so/my-integrations 에 접속합니다.
  2. New integration 을 누릅니다.
  3. 이름을 적습니다. 아무 이름이나 됩니다.
  4. 연결할 워크스페이스를 고릅니다.
  5. 종류는 Internal 을 고릅니다.
  6. 권한(Capabilities)에서 Read content 만 켜고 나머지는 끕니다. 검색만 하면 되니 쓰기 권한은 줄 필요가 없습니다.
  7. 저장하면 Internal Integration Secret 이 나옵니다. Show 를 눌러 복사해 위 칸에 넣으세요.
  8. 여기까지 하면 아직 아무것도 안 보입니다. 노션에서 검색되길 원하는 페이지를 열고, 오른쪽 위 ··· → 연결(Connections) → 방금 만든 이름을 고르세요. 상위 페이지에 연결하면 하위 페이지도 함께 잡힙니다.
  9. 연결한 페이지만 검색됩니다. 회사 문서라면 공유해도 되는 범위만 연결하세요.

없으면 공용 IP 할당량에 걸려 Stack Overflow가 거의 항상 막힙니다. 키를 넣으면 하루 300회에서 10,000회로 올라갑니다.

Stack Overflow 키 받는 방법 · 5분
  1. stackapps.com/apps/oauth/register 에 접속합니다.
  2. Stack Overflow 계정으로 로그인합니다. 없으면 Sign up 으로 만드시면 됩니다.
  3. Application name 에 앱 이름을 적습니다. 아무 이름이나 됩니다.
  4. Application description 에 한 줄 설명을 적습니다. 심사는 없습니다.
  5. Application URL 에 쓰시는 주소를 적습니다. 비워두셔도 됩니다.
  6. 아이콘은 건너뜁니다. I agree to the terms and conditions 를 체크합니다.
  7. Register application 을 누릅니다. 붙여넣기만 하면 빨간 경고가 남을 수 있으니, 그럴 때는 각 칸을 눌러 글자를 한 번 지웠다 다시 치면 사라집니다.
  8. 다음 화면에서 만료일을 물으면 절대(Never) 를 고릅니다. 30일이나 90일로 하면 그때마다 다시 발급해야 합니다.
  9. 값이 세 개 나옵니다. 그중 Key 만 복사해 위 칸에 넣으세요. Client Secret은 어디에도 넣지 마세요.

논문 검색(OpenAlex)이 여유 있는 대역으로 처리됩니다. 키가 아니라 연락처입니다.

JSON 출력이 켜진 인스턴스여야 합니다. 이걸 넣으면 결과 융합이 실제로 작동하기 시작합니다.

위 값은 모두 이 브라우저에만 저장됩니다. 검색할 때마다 서버로 보내 해당 API를 부르는 데만 쓰고 서버에는 남기지 않습니다.
